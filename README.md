## CAREERPILOT AI

Intelligent Job Discovery, Matching, Personalisation & Application Automation Platform

Project Type: Agentic AI / Intelligent Recruitment Platform

Project Domain: Artificial Intelligence, Natural Language Processing, Machine Learning, Web Automation, Recruitment Technology

Proposed Technology: Python, FastAPI, Next.js, PostgreSQL, Redis, Vector Search, LLMs, NLP, Playwright

Primary Users: Job seekers, professionals, graduates, career switchers

Application Model: Human-in-the-loop intelligent job application automation

## Backend Setup

# Conda setup
```bash
conda --version
conda create -n careerpilot python=3.12 -y
conda activate careerpilot
python --version
```

``` bash
cd backend
conda activate careerpilot 
pip install -r requirements.txt
python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```


## Frontend Setup

``` bash
cd frontend
npm install
npm run dev
```
